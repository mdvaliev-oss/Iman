# Слово

Платформа групповой подотчётности по трём пари. Группа друзей заключает пари и
полгода их держит; каждый видит выборы и прогресс остальных. Суть — «веришь ли ты
собственному слову».

- **Пари 1 — Страна:** стать экспертом по выбранной стране.
- **Пари 2 — Творчество:** довести до конца оригинальную работу в новом виде творчества.
- **Пари 3 — Недостаток:** осознанно воевать со своим главным недостатком.

## Возможности (MVP)

- Регистрация по инвайт-коду группы (приватно), вход по email/паролю.
- Профиль: имя, фото, «о себе» + выбор и цель по каждому из трёх пари.
- **Мои пари:** ежедневные чек-ины и серии (стрик), быстрый отчёт.
- **Участники:** каталог всех и их выборы.
- **Профиль участника:** его цели, серии и лента отчётов.
- **Лента:** отчёты всех (текст + фото), обновление в реальном времени.

Дальше по плану: реакции/комментарии, финальное голосование «кто изменился сильнее»,
таймер обратного отсчёта до конца полугода.

## Технологии

React + Vite + React Router + Tailwind + Supabase (Postgres, Auth, Storage,
Realtime). Деплой на Vercel. Данные — в общей базе Supabase; доступ ограничен
политиками RLS (каждый видит всех, менять может только своё).

## Запуск и деплой

См. **[SETUP.md](./SETUP.md)** — настройка Supabase (схема `supabase/schema.sql`),
переменные окружения и деплой на Vercel.

```bash
cd slovo
cp .env.example .env   # ключи Supabase
npm install
npm run dev
```
