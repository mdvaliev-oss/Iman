# Iman — трекер мухасабы

Приватное приложение для ежедневной мухасабы (самоотчёта): грехи, благие дела,
зикр, серии, цели и ежемесячная рефлексия. Работает как обычный сайт и как
приложение на телефоне (PWA) — устанавливается на экран «Домой», работает офлайн.

**Приватность.** Все данные хранятся только на вашем устройстве (`localStorage`) и
никуда не отправляются. Есть экспорт/импорт резервной копии в JSON.

## Возможности

- **Сегодня** — счётчики грехов и благих дел по группам, триггер дня, заметка,
  дата по хиджре.
- **Календарь** — тепловая карта баланса каждого дня.
- **Итоги** — сводные цифры и график по месяцам.
- **Серии** — сколько дней подряд без греха / с благим делом (текущая и рекорд).
- **Зикр** — счётчик-тасбих (истигфар, салават и др.) с целью и вибро-откликом.
- **Рефлексия** — итоги месяца (лучший/трудный день, частые триггеры) и выводы.
- **Цели** — годовые цели и мини-шаги по сферам жизни.
- **Настройки** — светлая/тёмная тема, вечернее напоминание, PIN-код,
  редактор своих категорий, бэкап.

## Технологии

React + Vite + Tailwind CSS + Recharts + lucide-react, PWA через `vite-plugin-pwa`.
Одна кодовая база для веба и телефона; структура готова к нативной обёртке
(Capacitor), если понадобятся сборки для App Store / Google Play.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки (--host для доступа с телефона)
```

Иконки PWA генерируются скриптом `node scripts/gen-icons.mjs` (уже лежат в `public/`).

## Установка на телефон

Откройте адрес приложения в браузере телефона → меню → «Добавить на экран Домой».
Дальше Iman работает как отдельное приложение, в том числе офлайн.
